Ethic Notes is a private, offline, zero-permission notes application for Android.

* Zero permissions declared: no internet, no broad storage access, no device tracking.
* Privacy Shield: blocks screenshots, recordings, and recent app previews.
* Storage Access Framework: export/import clean JSON or plain text files securely.
* Auto-save: writes notes continuously in the background without forcing titles or manual saves.
* Multi-selection: batch delete notes directly from the main list.
* Sovereign Ethic Ecosystem: integrated hub for libre, offline utilities.
* Multi-language: Universal English default, native Spanish, and per-app language selection on Android 13+.
